# 行情研究員雷達（公開版）

把六位加密貨幣 YouTuber 的行情判斷，拆成可以事後計分的結構化主張，
逐條到期驗證，並跟「依該標的×期限×方向算出來的盲猜基準」比較。

**看板：** https://hsintiger.github.io/kol-board/

## 這裡回答的問題

不是「誰比較準」，是「**誰能跟擲硬幣區分開來**」。

命中率單看沒有意義：BTC 單日漲逾 3% 的歷史機率只有 6%，一個月則是 30%——
用同一個基準去評「講短線的人」和「講月線的人」並不公平。所以每位研究員的
盲猜期望，是依他自己的 標的×期限×方向 組合、從 400 天價格史算出來的。

## 方法

- **主張為單位**：一支影片說「短線還會跌、月線看多」，那是兩條不同期限、
  不同方向的主張，分開計分。
- **edge = 前瞻命中 − 順勢率**。順勢率是他的方向跟前 7 天走勢一致的比例；
  edge 接近 0 代表他只是在覆述已經走完的行情。
- **顯著性檢定**：跟盲猜的差距要通過單尾二項式檢定才算數。沒通過就是
  「無法區分」，不給差別權重——樣本不足時給權重，比不給權重更危險。
- **反向採用有額外門檻**：「他一直錯」不等於「反著抄會賺」。要在**上漲與
  下跌兩種期間都低於盲猜期望**，才准把訊號反向。
- **路徑感知**：用日線高低算期間內最大順向／逆向幅度。方向最後對了、
  中途卻逆向超過一成的判斷，實務上多半已經被洗掉，不該跟一路順風的同分。

## 已知限制

- **取樣偏差**：相當比例的影片是會員限定，只看得到免費版。
- **只看過多頭**：目前多數已驗證主張落在上漲期間。任何從這份資料推出的
  權重，本質上都是在賭這段行情延續。
- **萃取誤差**：一部分主張被自動閘門標為期限或方向可疑而排除計分。
  那是萃取的錯，不是研究員的失誤。
